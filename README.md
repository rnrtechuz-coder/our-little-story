# Наша маленькая история

Романтический интерактивный сайт на чистом HTML, CSS и JavaScript. Он не требует Node.js, сборки, аккаунта или сервера для хранения данных.

## Запуск на Mac

Открой Terminal, перейди в папку проекта и запусти локальный сервер:

```bash
cd ~/Desktop/our-little-love-story
python3 -m http.server 8000
```

Открой <http://localhost:8000>. Чтобы остановить сервер, нажми `Control+C` в Terminal.

## Добавление фотографий

Лучше добавить пять фотографий (минимум — одну) в `public/images/us/` со следующими именами: `photo-01.jpg`, `photo-02.jpg`, `photo-03.jpg`, `photo-04.jpg`, `photo-05.jpg`. Первое фото будет обложкой, все пять появятся в галерее. На Mac скопируй их через Finder. Чтобы перенести снимки с телефона, отправь их на Mac через AirDrop или импортируй через USB, затем скопируй в эту папку.

Сайт без сборки не может автоматически прочитать список файлов в папке, поэтому для галереи используется список `photos` в [data.js](./data.js). Эти пять фотографий уже добавлены в манифест. Для новых снимков добавь запись в массив, например:

```js
const photos = [
  { src: 'public/images/us/photo-01.jpg', caption: 'Момент, который хочется оставить.', size: 'tall' },
  { src: 'public/images/us/photo-02.jpg', caption: 'Ещё одно наше фото.', size: 'wide' },
];
```

Поддерживаются `tall`, `wide` и `square`; подпись и размер можно не указывать. Первое изображение из списка также используется в обложке. Если список пуст или файл не найден, сайт покажет аккуратное состояние без фотографий. Используй собственные изображения и не добавляй в список файлы, которых нет в папке.

## Музыка (необязательно)

Положи свой аудиофайл в `public/audio/our-song.mp3`. Плеер попробует запустить его при открытии сайта. Браузеры могут блокировать звук до первого нажатия; если это произойдёт, нажми кнопку плеера. Загруженный M4A сохранён как `our-song.m4a`, рядом лежит MP3-копия для браузеров, которые не воспроизводят M4A. Чтобы использовать другое имя файла, измени `audio.src` в [script.js](./script.js). Сайт не загружает музыку самостоятельно.

## Редактирование текста и дат

В [data.js](./data.js) можно менять дату начала отношений, подписи фотографий, комплименты, подкаты, текст письма, письма «Открой, когда…», события таймлайна, причины и сообщения «порции милоты». Дату начала указывай в `CONFIG.startDate`; дата первых двух недель вычисляется автоматически как 14 дней после неё.

## Публикация на Vercel

1. Создай репозиторий GitHub с файлами проекта и отправь туда изменения.
2. На [vercel.com](https://vercel.com/) создай новый проект и импортируй этот репозиторий.
3. Выбери `Other` как Framework Preset. Build Command оставь пустой; для Output Directory укажи `.`.
4. Нажми Deploy. После публикации сайт будет доступен по HTTPS. Фотографии и аудио из папки `public/` публикуются вместе с сайтом.

Для временного деплоя также можно выполнить `npx vercel` из папки проекта и следовать подсказкам CLI.
